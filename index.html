Quatro desafios para testar as regras no seu ritmo. O treino é separado das salas e não altera a pontuação da disputa.

01 / CÉSAR

Desloque letras

Avance ou volte no alfabeto. A mesma regra transforma cada letra da mensagem.

02 / SUBSTITUIÇÃO

César e substituição tentam ocultar o texto. Binário, hexadecimal e Base64 representam dados em outro formato; sozinhos, não são criptografia.

      O PROJETO

      SOBRE O CIPHERQUEST

      CipherQuest é um projeto educacional desenvolvido pela Turma 2001 para apresentar criptografia, lógica e transformação de informações por meio de uma experiência interativa.

      O jogador criptografa e descriptografa mensagens, observa padrões e aprende como cada método funciona na prática. O projeto une tecnologia, educação e jogos para os alunos da escola.

      CRIPTOGRAFIA ≠ CODIFICAÇÃO

      Uma cifra usa uma regra e, em geral, uma chave para ocultar uma mensagem. Binário, hexadecimal e Base64 representam dados em outros formatos; por si só, não protegem o conteúdo.
